# THD AI – GitHub beginner's guide

A practical starting point for collaborating on student projects. Every cohort and experience level is welcome.

1. [Getting started](Getting-Started-with-GitHub.md) – repositories, cloning, branches, and your first contribution.
2. [Collaborating on projects](Collaborating-on-Projects.md) – issues, reviews, and pull requests.
3. [Team workflows](Understanding-Enterprise-Workflows.md) – a reference for larger collaborations.
4. [Communication and teamwork](Importance-of-Soft-Skills.md) – asking useful questions and giving constructive feedback.

## Build with THD AI

Members can create their own repositories and manage their projects. Non-members can contribute through forks and pull requests. Read the [community contribution guide](https://github.com/THD-AI/.github/blob/main/CONTRIBUTING.md) or ask in [Q&A](https://github.com/orgs/THD-AI/discussions/categories/q-a).

The original learning articles remain available. If an example is dated or confusing, open a small correction with the source you checked. Never paste credentials, private course keys, or personal information into examples.
